# ADR 0003: Node 24互換性と中国語ロケール

- Status: Accepted
- Date: 2026-10-02

## Context

AWS LambdaのNode.js 24ランタイムと開発環境の互換性を継続的に確認したい。また、既存の日本語・英語に加え、簡体字中国語をサイト全体で利用できるようにする。

## Decision

- CIはNode.js 24と26の両方で`pnpm verify`を実行する。開発の標準バージョンは26のまま維持し、root/APIの`engines.node`は24以上とする。
- `zh-CN`を静的生成する対応ロケールとして追加し、辞書、ツールメタデータ、作業領域のユーザー向け文言、言語切替、SEO/サイトマップを同じロケール識別子に接続する。

## Consequences

CIでNode.js 24の回帰を検出できる一方、検証時間は増える。中国語ページは静的出力の対象となる。共有UI、ツール説明、作業ガイド、データ駆動の各ラベルは翻訳カバレッジテストで監視する。Emoji名はUnicodeの`emoji-test.txt`とCLDRの日本語・簡体字中国語アノテーションから生成する。コード記号や公式の英語識別子など、翻訳対象ではない標準データはそのまま表示する。

## Alternatives considered

- 開発・CIの既定バージョンを24に下げる案は、現在のNode 26開発環境とLambdaのランタイムを混同するため採用しない。
- 中国語を英語の別名として扱う案は、利用者に中国語UIを提供しないため採用しない。
- `zh-TW`は今回の対象外とする。
